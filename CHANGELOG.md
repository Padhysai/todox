All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-01-26

### Added
- 🎨 Rich CLI interface with beautiful table output
- 🖥️ Interactive TUI (Terminal User Interface) with keyboard shortcuts
- ⚡ Priority management (Low, Medium, High) with color coding
- 📅 Due date tracking with ISO format
- 🏷️ Tag system for task organization
- 🔍 Fuzzy search for quick task lookup
- ⏱️ Built-in time tracking for tasks
- 📝 Notes support with `$EDITOR` integration
- 🔀 Git integration (automatic repo/branch detection)
- 🎯 Context filtering (filter tasks by current Git repo)
- 📊 Statistics and time spent tracking
- ✨ Beautiful visual indicators and emojis

### CLI Commands
- `add` - Create tasks with priority and due dates
- `list` - Display tasks in rich formatted table
- `done` - Mark tasks as complete
- `edit` - Edit task notes
- `start/stop` - Time tracking
- `search` - Fuzzy search tasks
- `stats` - View statistics
- `ui` - Launch TUI

### TUI Features
- Keyboard shortcuts (x, p, s, t, space, q)
- Priority cycling
- Sort by priority
- Real-time search filtering
- Visual task indicators
